How the check works

A model result is only as good as its paired readings.

Use device records with matching crop lot, timestamp, and inspection history. The interface checks what is present and makes gaps visible before prediction.

1. Check the source

The file inspector reports missing fields, invalid or duplicate timestamps, and recording gaps when a timestamp column is present. It does not create lot IDs or pair separate sensor files.

2. Map measured values

Map your CSV’s real column names to the model’s expected inputs. Leave a field unmapped when no measurement exists; prediction will name the missing values.

3. Read the result in context

Status probabilities describe current condition. Next-check risk is conditional on your stated inspection interval. The model does not claim continuous days remaining or prove a storage intervention works.
